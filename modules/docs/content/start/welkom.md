# Welkom

Deze handleiding legt uit hoe je de webshop beheert. Kies links een onderwerp.

| Onderdeel | Wat vind je er |
|---|---|
| **Start** | Het menu, talen, de testfase |
| **Webshop** | Producten, categorieën, merken, klanten, bestellingen, instellingen |
| **Pagina's** | De pagina's van de website, header en footer |
| **CMS** | Foto's, bestanden en SEO |

## Goed om te weten

- De beheeromgeving is in het Engels. Wil je ze in het Nederlands? Klik rechtsboven op je naam → **Preferences** → **Language**.
- Knoppen en menu's staan in deze handleiding in het **vet**, zoals in het Engels.
- Iets niet duidelijk, of mis je iets? Laat het ons weten.
