# Header en footer

## Header

Ga naar **Entries → Header**. Hier staat het hoofdmenu bovenaan de website (**Primary navigation**).

| Soort link | Wat |
|---|---|
| Navigation link | 1 link |
| Navigation link + menu | 1 link met een uitklapmenu eronder |

## Footer

Ga naar **Entries → Footer**.

| Veld | Wat |
|---|---|
| Footer navigation | Links onderaan de website |
| Legal navigation | Juridische links, bv. privacy en voorwaarden |

## Opgelet

- Elke taal heeft zijn eigen menu. Wissel van taal linksboven en controleer alle 3.
- Volgorde aanpassen: sleep een link.
