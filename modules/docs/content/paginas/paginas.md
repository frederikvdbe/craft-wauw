# Home en extra pagina's

## Home

Ga naar **Entries → Home page**. Er is maar 1 homepagina.

## Extra pagina's

Ga naar **Entries → Extra pages**. Bijvoorbeeld: Over ons, Contact, Verzending.

- Nieuwe pagina: klik op **New entry**.
- Volgorde en niveaus: sleep een pagina. Een pagina onder een andere pagina krijgt een URL eronder, bv. `/over-ons/team`.
- Maximaal 3 niveaus diep.

## Blokken

Een pagina bouw je op met blokken. Klik onder **Blocks** op **New entry** en kies een blok.

| Blok | Waarvoor |
|---|---|
| Text | Tekst met titels, lijsten en links |
| Media | Foto of video |
| Spacing | Witruimte tussen 2 blokken |
| Anchor | Een plaats op de pagina waar een link naartoe kan springen |

- Volgorde: sleep een blok.
- Een blok tijdelijk verbergen: zet het uit in het menu van het blok (de 3 puntjes).
